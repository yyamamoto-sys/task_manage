# 四半期切替の手順

クォーターをまたぐタイミングは、plan-app の中で **TF 構成が変わる** 唯一の節目です。
TF は自分が属するクォーターを1つ持ち、次の画面では「表示中・対象のクォーターに属する TF」だけが選択肢や集計に出ます。

- タスク追加（＋ボタン）のタスクフォース欄：現在のクォーターの TF
- タスク編集・サイドパネルの「＋ タスクフォースを追加」：タスクの期日（無ければ開始日）が属するクォーターの TF
- ダッシュボードの KR 別の表示、AI相談に渡す TF：現在のクォーターの TF

次Qの TF が揃っていないと、翌Qに入った時点でこれらの選択肢から TF が消えます。

## 全体の流れ

```
前Q末                     切替週                     翌Q初日
 ────────── ────────────────────── ──────────►
 次QのTF構成を決める      次QへTF移動・新設         メンバー周知
```

## ステップ1：次QのTF構成を決める（前Q末）

KR ごとに、TF を **継続／変更／廃止／新設** のどれにするかを決めます。決め方（会議・相談の場）はアプリの外で行います。

## ステップ2：管理画面で次Qの構造を反映（管理者）

設定 → **タスクフォース**（上部のクォータータブを次Qに切り替えて作業）：

1. **TF の追加・更新・廃止**
   - 新設：次Qのタブのまま新しい TF を作成（作成時のクォーターが自動的にセットされる）
   - 変更：既存 TF の name/leader を更新
   - 廃止：is_deleted（履歴は残る）
2. **既存TFを次Qへ移動**
   - 前Qから継続するTFはTF行の「移動」操作で次Qへ切り替える（TF自体は削除されない）
   - 1つのTFが同時に複数クォーターに属することはない（移動すると前Qからは外れる）

> ❗ **次Qへの移動・新設を忘れると**、翌Qに入った時点でそのTFがタスクのタスクフォース欄やダッシュボードに出てこなくなります。**翌Qの初日までに**完了させてください。

## ステップ3：メンバーに変更を周知（管理者）

クォーター切替は **全員が認識を揃える必要がある**節目です。最低限：

- 新設 TF とリーダー
- 廃止 TF
- 注力テーマの変更

を文書で共有してください。テンプレ：

```
件名：[plan-app] 〇Q運用開始のお知らせ
今期の Objective： <変更があれば>
KR1： <タイトル>
  TF1： <name> / リーダー <name>
  TF2： <name> / リーダー <name>
  ...
KR2： ...
変更点：
  - 廃止：TF <name>（理由：…）
  - 新設：TF <name>（理由：…）
今期の注力課題： …
```

## トラブル対応

### 翌Qに入ったのに TF の移動が間に合わない
- 管理者が設定 → タスクフォースで翌QへのTF移動・新設を完了させれば、その時点から選択肢に出ます
- 期日が前Qのタスクには、前Qの TF を引き続き紐づけられます（タスク編集の「＋ タスクフォースを追加」は期日のクォーターで絞り込むため）

### TF を廃止したのにタスクフォース欄に出てくる
- 該当 TF の `is_deleted` が true になっているか確認
- 設定 → タスクフォースで、そのTFのクォーターが表示中のQのままになっていないか確認
