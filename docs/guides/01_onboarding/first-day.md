# 初日にやること

plan-app を初めて触る方の **30分セットアップ**ガイドです。順番にやれば、明日からそのまま使い始められます。

## ステップ1：ログインする（2分）

1. ブラウザで plan-app の URL を開く（山本さんから共有されたもの）
2. 登録されたメールアドレスとパスワードでログインする
3. ログインしたメールアドレスがメンバー登録と一致していれば、自動で自分として開きます（名前を選ぶ画面は通常出ません）

> 「アクセス権がありません」と表示されたら、そのメールアドレスがメンバーとして登録されていません。管理者に、同じメールアドレスでのメンバー登録を依頼してください。
> 違うアカウントで入ってしまったら、サイドバー最下部の「⋯」を開くと **⏏ ログアウト**ボタンがあります（既定では折りたたまれています）。

## ステップ2：全体像を掴む（5分）

2つのモードを行き来して使うアプリです。サイドバー最上段の「📋 計画 / 🎯 OKR」で切り替えます。

| モード | 主な用途 |
|---|---|
| **📋 計画** | 日々のタスク・ダッシュボード・ガント・カンバン・リスト・ワークロード |
| **🎯 OKR** | 個人の四半期KRを月ごとに管理（月の計画・実施記録・振り返り・全体タブ・AIの見立てと下書き。週の目標状態は任意） |

![画面の全体図。画面の主要な領域に番号①〜⑤を付けて位置を示した模式図](../_img/screen-overview.svg)

詳しくは [plan-app の全体像（5分）](../00_overview.md) を読んでください。

## ステップ3：自分の関わるプロジェクト／KRを確認する（5分）

### 計画モードで
1. サイドバーの**プロジェクト一覧**で、自分が関わるPJをクリック
2. **ダッシュボード**で進捗を確認
3. 「プロジェクト」見出しの右にある「👤自分 / 🌐全件」トグルで、自分が担当のタスクを持つPJだけに絞れます。ダッシュボード・リスト・カンバン・ガントのタスクも自分の担当分に絞られます
4. 複数の部署に所属している場合は、サイドバーの「🏢 部署名」で表示する部署を切り替えます。別の部署のPJ・タスクは、その部署を選んだときだけ表示されます

### OKRモードで
1. サイドバーの **🎯 OKR** に切り替え
2. 上部のKRタブから自分の四半期KRを選ぶ（無ければ「＋ KRを追加」か「📥 Kintoneから取込」で登録）
3. 「◯月の計画」を確認・入力。「実施記録」と「📝 振り返り」も記録できます（週の目標状態は任意です）

詳しくは [個人OKRの使い方](../02_modes/personal-okr.md) を参照してください。

## ステップ4：自分のタスクを見る（5分）

1. 計画モード → **ダッシュボード**で「今週のタスク」を確認（「全員 / 自分のみ」で切り替え）
2. または **カンバン**でToDo／進行中／完了をドラッグ&ドロップ
3. **リスト**で絞り込み・CSV出力もできる（ツールバー右端の「⋯」→「⭳ CSV出力」）

タスクをクリックすると、PCでは右側のサイドパネルが開き、ステータス・期日・担当者などを変更できます（モバイルやダッシュボードからはモーダルが開きます）。
**変更は自動では保存されません。** 編集面の「保存」ボタン（または Enter／Ctrl+Enter）を押して確定します。未保存のまま閉じようとすると確認が出ます。
タスクを増やすときは、PCのリストなら各グループの一番下の「＋ タスクを追加」にタスク名を入れて Enter を押すだけで登録できます（続けて入力できます）。
登録・更新の手順は [タスクの登録と更新](../02_modes/tasks.md) を参照してください。

## ステップ5：困った時の場所を覚える（3分）

1. **`?` ボタン** — ダッシュボード・AIツール・設定ページの3つの画面にあり、押すとその画面の使い方が表示されます（カンバン・ガント・リスト・ワークロード・OKRモードにはありません）
2. **サイドバー最下部の「⋯」の中にある📖 ガイド** — このガイド全体の目次
3. [FAQ](../06_troubleshooting/faq.md) — よくある詰まり
4. それでも解決しなければ山本さんに連絡

![サイドバー最下部の「⋯」を開いたところ。ガイド・設定・招待コードを入力・テーマ切替・ログアウトが並ぶ模式図](../_img/sidebar-more-menu.svg)

## ステップ6：自分の役割の専用ガイドを読む（10分）

あなたの役割によって、追加で読むページが変わります：

| あなたは… | 次に読むページ |
|---|---|
| 管理者（Objective/KR/TF登録・メンバー管理） | [管理者ガイド](../03_roles/admin.md) |
| TFメンバー（タスクを動かす） | このページで終わり。あとは慣れていけばOK |

> 「KR代表」「ファシリ」という役割は、OKRモードが個人単位に変わる前のグループ運用向けの
> 区分です。現在は個人KRの管理が中心のため、専用ガイドは用意していません。
> 自分の四半期KRを登録・更新する操作は上のステップ3を参照してください。

## ステップ7：今週の最初の操作を1つだけやってみる

実際に手を動かすのが一番早いです。役割ごとにおすすめの初手：

- **TFメンバー** → 自分のタスクの状態を1つ「進行中」に変えて、「保存」を押してみる
- **KR代表・ファシリ** → OKRモードで自分のKRの「◯月の計画」を1つ書いてみる
- **管理者** → サイドバー最下部「⋯」の **⚙ 設定** を開き、左の目次「🔧 部署の管理」で Objective・KR・TF・メンバー登録を確認（一般メンバーにはこの項目は表示されません）

これで今日は終わりで OK です。明日以降は実際の業務に合わせて使ってください。

## 1週目の目標

- 自分のタスクを毎日触る（状態更新でOK。変更したら「保存」を押す）
- 自分のKRがあれば、月の計画・実施記録・振り返りを更新する（週の目標状態は使いたい場合のみ）
- 詰まったら、`?` ボタンのある画面では `?` ボタン、それ以外は「⋯」の中の📖 ガイド

困ったら遠慮なく山本さんに連絡を。
