# ダッシュボード（計画モード）

計画モードのトップ画面。**自分のタスク・PJ全体・期限アラート**を1画面で把握できます。画面のヘッダーには `?` ボタンがあり、押すとこの記事が開きます。

## 主な構成

画面上部で、**「対象PJ」のプルダウン**（先頭は「すべてのPJ」。1つ選ぶとそのPJに絞られる。アーカイブ済みのPJは出ず、完了のPJは「（完了）」付きで出る。サイドバーでPJを選んでいる間は出ない）による絞り込みと、「全員 / 自分のみ」の切り替え（サイドバーの「👤自分 / 🌐全件」と連動）、「全PJをAI分析」ボタンを使えます。

| エリア | 内容 |
|---|---|
| **KPIタイル** | 期限超過／今日締切／今週締切／進行中／今週の完了率の5つ |
| **🔔 自分のリマインダー** | 自分のタスクの期限の知らせ。対象期間（3・7・14・30日前〜）を選べ、「🔔 通知設定」ボタンから通知の設定を開く |
| **締切の見通し・完了ペース** | それぞれ専用のカードで表示される |
| **KR進捗サマリー** | KRの進捗のまとめ |
| **期限アラート** | 期日切れ・期日間近のタスクの抜粋 |
| **今週のタスク** | 期限が今日から7日以内のタスク。「全員 / 自分のみ」で担当者を絞れる |
| **PJ進捗一覧** | 各PJのタスク達成率・状態の集計 |
| **自分へのメンション** | 自分宛て（@名前）のメンションがあるタスク |
| **ToDo進捗一覧** | ToDoの進捗の一覧 |
| **ProjectKarte（PJ選択時）** | サイドバーで PJ を選ぶと、そのPJの要約カードが上部に表示される。AI分析もここから |

PJを選んでいる間は、自分のリマインダー・KR進捗サマリー・自分へのメンション・ToDo進捗一覧は表示されません。
PJが1つも無いときは「AIでプロジェクトを作る」が案内されます。

## ProjectKarte（PJ選択時）

目的（✏で編集）・オーナー・期間・ステータスの内訳（未着手／進行中／期限超過／今週期限／期日未設定）・担当者別の負荷・マイルストーン（追加・編集・削除）・紐づくKR（表示のみ）・グループごとの完了数（プロジェクトにグループがあるとき）が並びます。「⚙ このPJの設定」から、PJの基本情報・招待・関わるメンバーを開けます。

## PJ別 AI 分析

ProjectKarte の **「✨ このPJをAI分析」** ボタンで、そのPJの直近状況を AI が要約。2回目以降はボタン名が「AI分析を更新」になります。

- 1 PJ あたり**最新2件まで**を Supabase に保存（共有）
- 「最新の分析を見る」で、保存された分析を全員が同じ内容で見られる
- 旧分析は履歴として確認可

ダッシュボード上部の **「全PJをAI分析」** は、全PJを横断した分析を返します。こちらの結果は保存されません。

## サイドバー連動

- **「👤自分 / 🌐全件」トグル**（サイドバーの「プロジェクト」見出しの右）でPJ一覧を絞り込み。「自分」は、自分が担当のタスクを持つPJだけを表示します
- PJ を選ぶとダッシュボードの ProjectKarte が表示され、一部のカードは非表示になる（上記）
- 「🌐全件」にすると全PJを横断表示

## ガント／カンバン／リスト／ワークロードとの関係

ダッシュボードは**要約と入口**です。詳細操作は：
- **ガント**：期間と期日のカレンダー表示
- **カンバン**：ステータス列のドラッグ&ドロップ管理
- **リスト**：絞り込み・CSV出力・大量編集
- **ワークロード**：メンバー別の担当タスク件数と負荷
