# 個人OKRの使い方（OKRモード）

サイドバー最上段の「🎯 OKR」に切り替えると開く、個人の四半期KRを月ごとに管理する画面です。Kintoneの個人OKRが正本で、評価の確定はKintone側で行います。この画面は、月の計画・実施記録・振り返りを整理し、AIの見立てや下書きを使うための場所です。

- 入力した内容が見えるのは本人だけです（管理者や同僚には見えません）
- 初めて OKR に切り替えると紹介のポップアップが出ます。承認するとガイドツアーが始まります
- この画面には `?` ボタンがありません。ガイドは「⋯」の中の📖 ガイドから開きます

![個人OKRの1か月の流れ。計画・実施記録・振り返りの順に進む模式図](../_img/personal-okr-month.svg)

## 画面の見方

| 場所 | 内容 |
|---|---|
| **対象期** | 年・四半期・月を選ぶ。月を変えても、選んでいるKRのタブは保持される。その月のウェイト合計が100%でないと警告が出る（警告のみ） |
| **KRタブ** | 自分の四半期KRがタブで並ぶ。タブにはその月のウェイト（%）が出る（月ごとに上書きしている場合は「＊」付き）。「＋ KRを追加」「📥 Kintoneから取込」で登録する |
| **全体タブ** | KRタブの先頭。月全体・四半期全体の振り返りを書く |

KRの内容（対象業務カテゴリ・実施内容・得意領域の強化・苦手領域の克服・達成基準・補足）は、「✏️ このKRを編集」で直せます。編集画面で、そのKRを対象にする月（1・2・3か月目）を選べます。対象外の月には、そのKRのタブが出ません。

## 月の計画を書く

KRタブを選ぶと、「◯月の計画」に次の項目があります。

- 位置づけ／当月に取り組む内容／当月末の達成目標と証拠／リスクと依存関係
- 今月のウェイト（%）／当月末の達成度バンド
- 「✦ 前月をふまえて下書き」：AIが前月までの内容をふまえて計画を下書きする
- 「📋 全文をコピー（Kintone用）」：Kintoneに貼り付ける形式でコピーする

**過去月も編集できます。未来月は編集できません。** 未保存のままKR・月・四半期を切り替えようとすると、確認が出ます。

## 週の目標状態を使う（任意）

W1〜の週カードに「この週末にこうなっている」を書き、◯達成／△一部／✕未達で自己評価できます。**使いたい人だけが使う任意の機能です。** 記入が無くても、AIや画面から指摘されることはありません。週にタスクを紐づけると、遅れや先行待ちが表示されます。

## 実施記録を残す

計画外の対応や方針転換など、実際に起きたことを自由に書きます。振り返りの下書きなど、AIの材料にもなります。

## 振り返りを書く

KRパネルの下部の **「📝 振り返り」** に、振り返りの本文・自己評価%・GM評価%・GMコメントを記録します。過去月も編集できます。

- 「📝 振り返りの下書き」：AIが振り返りの下書きを作る。自己評価%や達成度バンドの数値はAIが決めず、人が決める
- 「📋 全文をコピー（Kintone用）」：Kintoneに貼り付ける形式でコピーする

**全体タブ**では、月全体・四半期全体の自己評価%・GM評価%・振り返りの本文を記録できます。「✦ 振り返りの下書きを生成」で、AIの下書きも使えます。

## これから（当月のみ）

当月のKRには、残り週数・月末までの日数・（週の自己評価があれば）その積み上げ・紐づくタスクの遅延／停滞／先行待ちの件数が出ます。
「✦ 見立てを出す」（解析後は「再解析」）を押したときだけ、AIが見立て・次の一手・捨てる候補・バンド判定を作ります。押さない限り、AIは動きません。
バンドの表示は、「🎯 Kintoneの狙い」「✦ AI判定」「● 自分で決定」の3種類が区別されます。

## AIに聞く・メモ・Kintone取込

- **迷ったらAIに聞く**：当月のKRパネルの「AIパネルを開く」から「✦ OKR相談」が開く。KRの内容・今月の計画・週の目標・タスクの状況・直近のメモをふまえて答える
- **メモ**：KRごとに追記できる、自分だけが見えるメモ。直近の数件は、当月のAI解析の材料になる
- **📥 Kintoneから取込**：Kintoneの個人OKRのPDFやテキストを、AIが読み取ってKR・月次の計画・振り返りに展開する。取り込む前に、内容を確認して直せる

個人OKRのメモは、計画モードの「AI相談」には渡されません。
