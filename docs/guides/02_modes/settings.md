# 設定ページ

一般メンバーが自分の名前・見た目・通知を変えるページです。左の目次は「プロフィール」「表示」「通知」「困ったとき」の4つです。「部署の管理」は管理者にだけ表示されます。

## 開き方

- **PC**：サイドバー最下部の「⋯」を押し、開いた項目から「⚙ 設定」を選びます（「⋯」は最初は閉じています）。サイドバーを折りたたんでいるときは、歯車のアイコンが常に並びます。
- **モバイル**：画面上部のヘッダーにある歯車（⚙）を押します。
- ベル（🔔）の「⚙ 通知設定」と、ダッシュボードの「🔔 通知設定」からは「通知」を直接開けます。

![サイドバー下部の「⋯」を開いたところ](../_img/sidebar-more-menu.svg)

## 👤 プロフィール

| 項目 | 変えられるか |
|---|---|
| 表示名（40字まで） | 変えられる |
| 短縮名（20字まで） | 変えられる。担当者欄など狭い場所に出る名前。空欄にすると表示名の最初の語になる |
| アバターの色 | 変えられる |
| メールアドレス・権限 | 変えられない（表示のみ） |

メールアドレスと権限は、部署の管理者が「部署の管理」→「メンバー」で変更します。変更したら「保存」を押します。

## 🎨 表示

このブラウザでの見え方だけを変えます。他の人や他のパソコンには影響しません。
- **テーマ**：ライト／ダーク
- **言語**：日本語／English（英語は一部の画面のみ対応）
- **一覧の表示密度**：シンプル（主要4列）／詳細（優先度・工数を含む）
- **サイドバーの幅**：ドラッグで変えた幅を「既定の幅に戻す」（PCのみ）

## 🔔 通知

通知は次の2つの「知らせ方」で届きます。

- **アプリ内通知**：ベル（🔔）に表示されます。既定でオンです。
- **Windows通知**：アプリを閉じていても画面右下に出ます。**既定ではオフ**で、本人がオンにしたときだけ届きます。ブラウザの許可ダイアログが出たら許可します。

Windows通知は**PC・ブラウザごとの設定**です。別のPCやブラウザでは、そこでもう一度オンにします。Teams の中では設定できないため、ブラウザでこのアプリを開いて設定します。

「通知する内容」の表で、種類ごとに知らせ方を選びます。

| 種類 | 内容 |
|---|---|
| 期限超過 | 担当タスクの期日を過ぎたもの（平日1回） |
| 今日期限 | 担当タスクの期日が今日のもの（平日1回） |
| メンション | コメントで「@自分」と書かれたとき（アプリを開いている間） |
| 管理者からのお知らせ | 管理者からの連絡。アプリ内には必ず届き、オフにできない |

- **送信時刻**：期限の通知が届く時刻を、7:00〜19:00の30分刻みから選びます（既定は8:30）。対象のタスクが無い日は届きません。
- **テスト通知**：「テスト通知を送る」で、このブラウザに届くかを確かめられます。
- **届かないとき**：同じ画面の「通知が届かないとき」に、ブラウザの通知の許可、Windowsの通知設定、応答不可（集中モード）の確認手順があります。

## 🛟 困ったとき

- **再読み込み**：画面が固まった・最新の内容が出ないとき
- **表示の設定を初期化**：サイドバーの幅や一覧の表示などを最初の状態に戻します（テーマ、言語、データ、ログイン状態は消えません）
- **ガイドを開く**／**ツアーをやり直す**／**キーボードショートカット**の一覧／**バージョンと更新履歴**
- **この部署の管理者**：メンバーの追加や権限・メールアドレスの変更を依頼する相手の一覧です
- **ログアウト**
