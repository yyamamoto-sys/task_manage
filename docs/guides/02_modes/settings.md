# 設定画面

自分の名前・見た目・通知を変える画面です。開くと、やりたいことごとのカードが並んだ一覧が出ます。カードを押すと、その設定のページが開きます。一覧に戻るには、ページ上部の「← 設定」を押します。

一般メンバーに出るのは「個人」の5枚です。部署の管理者には「部署の管理」、全社スーパー管理者には「アプリの管理」のカードも出ます（権限のないカードは表示されません）。

## 開き方

- **PC**：サイドバー最下部の「⋯」を押し、開いた項目から「⚙ 設定」を選びます（「⋯」は最初は閉じています）。サイドバーを折りたたんでいるときは、歯車のアイコンが常に並びます。
- **モバイル**：画面上部のヘッダーにある歯車（⚙）を押します。モバイルではカードが1列の一覧になります。
- ベル（🔔）の「⚙ 通知設定」と、ダッシュボードの「🔔 通知設定」からは「通知の受け取り方」を直接開けます。

![サイドバー下部の「⋯」を開いたところ](../_img/sidebar-more-menu.svg)

## 保存のしかた

設定のページは、次のどちらかの方法で保存されます。

- **押した時点で保存**：テーマ・言語・一覧の表示密度・通知のオン／オフなど。操作した欄の横に「✓ 保存しました」が1.5秒だけ出ます。保存できなかったときは元の値に戻り、エラーが出ます。
- **「保存」ボタンで保存**：プロフィール・パスワード・各管理ページの入力フォームなど。ボタンは3つの状態をとります。変更がないときは「✓ 保存済み」（押せません）、変更したあとは「保存」（左に「未保存の変更があります」）、保存中は「保存中…」です。保存に失敗したときはフォームの下にエラーが残り、入力した内容は消えません。

保存していない変更があるまま、「← 設定」・✕・ほかの画面への移動・ログアウトをすると、確認が出ます。

## 個人

### 👤 プロフィール

| 項目 | 変えられるか |
|---|---|
| 表示名（40字まで） | 変えられる |
| 短縮名（20字まで） | 変えられる。担当者欄など狭い場所に出る名前。空欄にすると表示名の最初の語になる |
| アバターの色 | 変えられる |

変えたら「保存」を押します。

### 🔑 アカウント

- **メールアドレス・権限**：表示のみです。部署の管理者が「部署の管理」→「メンバー」で変更します。
- **パスワードを変更**：サンプル閲覧のゲストには出ません。
  1. 「新しいパスワード」と「新しいパスワード（確認）」に、同じ6文字以上のパスワードを入れます。
  2. 「パスワードを変更」を押します。押すまでは変わりません。
  3. 「パスワードを変更しました」と出れば完了です。今のログインはそのまま使えます。
- **ログアウト**：別のアカウントでログインし直すときに使います。

セキュリティの設定により、ログインしてから時間がたっていると変更が拒否されることがあります。その場合は画面にエラーが出ます。一度ログアウトして、ログイン画面の「パスワードをお忘れの方はこちら」から再設定してください。パスワードを忘れたときも同じ手順です。

### 🎨 表示

このブラウザでの見え方だけを変えます。他の人や他のパソコンには影響しません。
- **テーマ**：ライト／ダーク
- **言語**：日本語／English（英語は一部の画面のみ対応）
- **一覧の表示密度**：シンプル（主要4列）／詳細（優先度・工数を含む）
- **サイドバーの幅**：ドラッグで変えた幅を「既定の幅に戻す」（PCのみ）

### 🔔 通知の受け取り方

通知は次の2つの「知らせ方」で届きます。

- **アプリ内通知**：ベル（🔔）に表示されます。既定でオンです。
- **Windows通知**：アプリを閉じていても画面右下に出ます。**既定ではオフ**で、本人がオンにしたときだけ届きます。ブラウザの許可ダイアログが出たら許可します。

Windows通知は**PC・ブラウザごとの設定**です。別のPCやブラウザでは、そこでもう一度オンにします。Teams の中では設定できないため、ブラウザでこのアプリを開いて設定します。

「通知する内容」の表で、種類ごとに知らせ方を選びます。

| 種類 | 内容 |
|---|---|
| 期限超過 | 担当タスクの期日を過ぎたもの（平日1回） |
| 今日期限 | 担当タスクの期日が今日のもの（平日1回） |
| メンション | コメントで「@自分」と書かれたとき（アプリを開いている間） |
| 管理者からのお知らせ | 管理者からの連絡。アプリ内には必ず届き、オフにできない |

- **送信時刻**：期限の通知が届く時刻を、7:00〜19:00の30分刻みから選びます（既定は8:30）。対象のタスクが無い日は届きません。
- **テスト通知**：「テスト通知を送る」で、このブラウザに届くかを確かめられます。
- **届かないとき**：同じページの「通知が届かないとき」に、ブラウザの通知の許可、Windowsの通知設定、応答不可（集中モード）の確認手順があります。

### 🛟 困ったとき

- **再読み込み**：画面が固まった・最新の内容が出ないとき
- **表示の設定を初期化**：サイドバーの幅や一覧の表示などを最初の状態に戻します（テーマ、言語、データ、ログイン状態は消えません）
- **ガイドを開く**／**ツアーをやり直す**／**キーボードショートカット**の一覧／**バージョンと更新履歴**
- **この部署の管理者**：メンバーの追加や権限・メールアドレスの変更を依頼する相手の一覧です

## 部署の管理（管理者のみ）

部署の管理者と全社スーパー管理者に出ます。Objective・KR、Task Force・ToDo、プロジェクト、メンバー、メンバータグ、部署、プロジェクト招待、AI使用量、お知らせの送信の9枚です。内容は[設定パネル概要](../05_admin/settings-overview.md)を参照してください。表示部署が複数あるときは、見出しの行とそれぞれのページの上に「編集対象の部署」が出ます。編集対象は、サイドバーの「表示部署」に従います。

## アプリの管理（全社スーパー管理者のみ）

ローディングのヒント、バックアップ、期限リマインドの実行状況、利用者の画面のエラーの4枚です。
