# タスクの登録と更新（計画モード）

一般メンバーが毎日使う、タスクの登録・更新・自分のタスクの探し方をまとめた記事です。編集は**「保存」ボタンで確定する方式**（自動保存ではありません）です。

![タスクを「追加」で登録し、「保存」で更新を確定する流れ](../_img/task-save-flow.svg)

## 登録する

| 入口 | 動き |
|---|---|
| リストの各グループの一番下「＋ タスクを追加」（PC） | その場でタスク名・担当者・開始日・期日を入れて Enter で登録する（下の「リストでその場で追加する」を参照） |
| 右下の「＋」→「＋ タスクを追加」 | 計画モードのときだけ表示される。常にポップアップが開く（リストの中で入力したいときは、各グループの下の「＋ タスクを追加」を使う） |
| Ctrl+K（検索）→「新規タスクを追加」 | 検索パレットから開く |
| カンバンの各列の下「＋ タスクを追加」 | その列のステータスで作成される |
| カレンダーの日付セル | 期日が入った状態で開く |
| リストの最上位タスク行「＋ 子タスク」 | 親を固定して追加する |

登録モーダルの項目は次のとおりです。

- **タスク名**（必須）／担当者／開始日／期日／優先度（高・中・低）
- プロジェクト／グループ（そのプロジェクトにグループがあるとき。下の「グループ」を参照）
- 親タスク／子タスク（1行1件で、複数を同時に登録できる）
- 成果物（何をこのタスクの成果物とするか。URL を書くとリストの📎から開ける）
- メモ（「@名前」でメンションを書ける。「追加」を押すと相手に通知が飛ぶ。条件は「メンション」の節を参照）

入力したら、モーダル下の **「追加」ボタン**を押して登録します（タスク名の欄で Enter を押しても登録されます）。

### リストでその場で追加する（PC）

リストの各グループ（まとめ方がPJ別・担当者別・状態別・タグ別のいずれでも）の一番下に「＋ タスクを追加」の行があります。ポップアップを開かずに登録できます（モバイルのカード表示には出ません。右下の「＋」から登録します）。

1. 「＋ タスクを追加」を押すと、その行が入力欄になります。
2. タスク名を入れて **Enter** を押すと登録され、同じグループの一番下に次の空の入力欄が出ます（続けて入力できます）。
3. **Tab** で 担当者 → 開始日 → 期日 の順に移れます。担当者・日付は行のセルと同じ操作です（日付は Enter か押して選びます）。
4. **Esc**（または行末の「✕」）で入力をやめます。タスク名が空のときは登録されません。

- そのグループの属性が初めから入ります。PJ別ならそのPJ（「プロジェクト未設定」はPJなし）、担当者別ならその担当者（この場合、担当者は変えられません）、状態別ならその状態、タグ別ならそのタグです。PJを選んで絞り込み中は、どのまとめ方でもそのPJに作られます。担当者の初期値は自分です（担当者別のグループではそのグループの担当者）。
- 親タスクのないタスクとして作られます。PJ・ToDo・KR・親タスクなども決めたいときは、行の端の「詳細を入れて追加」を押すと、入力済みの内容を引き継いでポップアップが開きます。
- フィルターや検索で絞り込み中に、作ったタスクが条件に合わず見えないときは「追加しました（今の絞り込みでは表示されません）」と知らせます。
- 名前を入れたまま別の画面・部署へ切り替えたりログアウトしようとすると、保存していない旨の確認が出ます。Esc でやめたときは確認なしで破棄されます。

議事録や資料からまとめて登録するときは [資料インプット](./meeting-import.md)、相談しながら登録するときは [AI相談](./consultation.md) を使います。

## 更新する

リスト・カンバン・ガントの行・カード・バーをクリックすると編集面が開きます。PCでは右側のサイドパネル、モバイルでは下から出るシートです。ダッシュボード・ワークロード・カレンダー・マイページ・AI提案のタスクからはモーダルが開きます。

編集面で変えられる項目：タスク名／ステータス／優先度／担当者（複数可）／プロジェクト／グループ／親タスク／先行タスク／開始日／終了日（期日）／工数（時間）／成果物／コメント・メモ／タグ。下部に「変更履歴」「🗑 削除」「保存」があります。

**タグの編集欄があるのは、モーダル版の編集画面（モバイルの下から出るシート、ダッシュボード等から開くモーダル）だけです。** PCの右側のサイドパネルには、タグの編集欄がありません。

## グループ（プロジェクトの中の区分）

プロジェクトの中を「第1回」「準備」のような区分に分ける機能です（部署のグループとは別のものです）。

- リストでまとめ方が「PJ別」のとき、プロジェクトの一番下の「＋ グループを追加」で作ります。グループの見出しの「⋮」から、名前の変更・上下の並べ替え・削除ができます。削除してもタスクは消えず「未分類」に移ります
- 各グループの一番下の「＋ タスクを追加」で、そのグループにタスクを作れます。タスクの行をほかのグループの見出しや行にドラッグすると、グループを移せます
- 1つのタスクが入るグループは1つです。子タスクは親タスクと同じグループで、親を移すと子も一緒に移ります
- タスクのプロジェクトを変えると、グループは「未分類」に戻ります
- ガントでは、プロジェクトの中がグループの見出し行で区切られ、折りたためます。見出しの ⋮ メニューや ⠿ のドラッグで、グループの順番も変えられます（作成・名前変更・削除はリストで行います）。カンバンはプロジェクトを選ぶと「グループ」で絞り込めます。ダッシュボードのプロジェクトカルテに、グループごとの完了数が出ます
- 名前の変更・削除は、プロジェクトの基本情報と同じく、同じ部署の誰でもできます

## 成果物

編集画面・登録の「成果物」欄に、そのタスクの成果物（何ができたら完了か）を書きます。本文に http／https の URL を書くと、リストのタスク名の横に📎が出ます。押すと新しいタブで開きます。マウスを乗せると成果物の説明（URL を除いた本文の先頭）が出ます。URL が複数あるときは最初の1件を開き、残りは編集画面の成果物欄の下に並びます。AI相談には URL を除いた説明だけが渡ります。

## 保存する

- 変更したら、編集面の **「保存」ボタン**を押して確定します。Enter（1行の入力欄のとき）や Ctrl（Cmd）+Enter でも保存できます。メモ・コメント欄の Enter は改行です
- 変更が無いときは、ボタンが「✓ 保存済み」の表示になって押せません
- 未保存のまま閉じる・別のタスクへ移る・画面を切り替えると、確認が出ます
- 他のメンバーが先にそのタスクを更新していると「他のメンバーがこのタスクを更新しました」と警告が出て、保存時に上書きするかどうかを確認されます
- **次の項目は「保存」を待たず、操作した瞬間に反映されます**：先行タスクの追加と解除、子タスクの付け外し

## 複数のタスクをまとめて扱う

リストとガントはチェックボックスで選ぶと、上に一括操作バーが出ます（カンバンはカードを Ctrl／Cmd＋クリック）。ガントのチェックボックスは左の列のタスク行にあり、リストと同じ操作（クリックで親子ごと選択・Shift＋クリックで範囲選択）です。プロジェクト・グループ・人の見出し行にはありません。

- **範囲選択**：チェックボックス（または行）を Shift＋クリックすると、最後に選んだ行からクリックした行までを選びます
- **📁 プロジェクトを移す…**：移動先を選ぶと確認が出ます。子タスクは親と一緒に移り、グループは「未分類」になります。子だけを選んで親を選んでいないときは、その子が親から外れて移動先の最上位のタスクになります（確認画面に件数が出ます）。直後なら「元に戻す」で戻せます
- **📅 日程をずらす**：日数（プラスで後ろへ・マイナスで前へ。土日は数えない営業日ではなく暦日）を入れて「ずらす」。期日が無い・完了のタスクはずらさず、その件数が表示されます。後続タスクの自動調整と「元に戻す」はガントと同じです
- **まとめてドラッグ**（リスト）：選択中の行の ⠿ をドラッグして行の上か下に落とすと、選んだタスク全部を表示順のまま移します。子タスクだけを別の親・最上位へまとめて移す操作は拒否され、理由が表示されます（1件ずつドラッグしてください）
- **グループの並べ替え**（リスト・ガント）：グループの見出しの ⠿ をドラッグすると、同じプロジェクトの中で順番を入れ替えられます（⋮の「一番上へ・上へ・下へ・一番下へ」でも同じです。「未分類」は先頭固定）

## ステータスを変える

ステータスは ToDo／進行中／完了／保留／中止の5種類です。

- 編集面の5つのボタン、カンバンの列間のドラッグ、複数選択して出る一括バーで変えられます
- リストの「状態」列は表示のみで、ここからは変えられません。親タスクのステータスは子タスクから自動で決まります
- **先行タスクがすべて完了または中止になるまで、完了にできません**（「先行タスク「…」が未完了のため完了にできません」と表示されます）。着手（ToDo→進行中）は、先行が未完了でも警告が出るだけです
- 未完了の子がある親を完了にしたときも、警告が出るだけです。完了にすると完了日が入ります

## 期日・担当者・階層・依存

| 項目 | 変え方と注意 |
|---|---|
| 期日・開始日 | 編集面の日付欄、リストの期日セル（クリックで直接編集）、ガントのバーのドラッグ。期日が過ぎた未完了タスクには「期限超過」が付く。先行タスクの期日を後ろにずらすと、後続タスクが自動で後ろ倒しされる（トーストの「元に戻す」で戻せる） |
| 担当者 | 編集面（複数可）、リスト・カンバン・ダッシュボードの担当者セル。候補は、表示部署のメンバー、そのPJの参加者、今の担当者。PJの参加者には、他の部署の人や、招待で参加した人が含まれることがある。PJに紐づいていないタスクでは、表示部署のメンバーと今の担当者だけが候補になる |
| 階層 | 親→子の2層。編集面の「親タスク」、リストの「＋ 子タスク」で設定する。子を持つタスクは親にできない |
| 先行タスク | 編集面の「先行タスク（このタスクの前に完了すべきタスク）」。循環する依存は作れない |

## 削除と元に戻す

削除は確認のあとに行われます。削除すると「元に戻す」付きのトーストが出て、直後に Ctrl（Cmd）+Z でも戻せます。これはモーダル版の編集画面（モバイルのシート、ダッシュボード等から開くモーダル）でも、PCの右側のサイドパネルでも同じです。編集面の「変更履歴」では直近20件（90日分）を確認でき、一般メンバーは自分の変更だけ「↺ 元に戻す」で戻せます。

## ガントの拡大・縮小

ガントの右上のツールバーに、「－」「＋」とスライドバーがあります。1日あたりの幅を 4〜80px の間で細かく変えられ、今の値が「28px/日」のように右に出ます（初期値は28px/日）。幅に合わせて行の高さや文字も変わり、縮小すると多くの行を見渡せます。「全体表示」を押すと、表示中のタスク全体が1画面に収まる倍率になります。

- **スライドバー**：つまみをドラッグするか、つまみを選んで矢印キーで動かす
- **「－」「＋」ボタン・キーボードの「－」「＋」**：1回で約1.25倍（または1/1.25）ずつ変わる
- **Ctrl（Macは Cmd）＋マウスホイール**：ガントのバーの領域の上で回すと、マウスの位置にある日付を動かさずに拡大・縮小する。トラックパッドのピンチも同じ。ガントの領域の外では、ブラウザ全体の拡大縮小のまま
- 幅が狭いときは、日の数字が月曜だけになり、週の表示も「W2」のように短くなる
- 選んだ倍率は、このブラウザに保存される。設定ページの「表示の初期化」で初期値（28px/日）に戻る

## メンション（@名前）

メモ・コメント欄に「@名前」と書くと、メンションになります。

- **相手に通知が飛ぶのは、編集画面（モーダル版・PCの右側のサイドパネルとも）でコメントを書いて「保存」したとき、または「タスクを追加」の登録画面で書いて「追加」したときです。** 通知は、相手が Windows通知をオンにしていて、アプリのタブを開いている間に届きます
- どの画面でも、「@」を入力すると候補が出ます
- ダッシュボードの「自分へのメンション」は、コメントに「@自分の名前」が入っている未完了のタスクを文字列で拾います。そのため、どの画面で書いたメンションでも、ここには出ます

## 自分のタスクを見つける

- **ダッシュボード**の「今週のタスク」を「自分のみ」にする。「🔔 自分のリマインダー」にも期限の近いタスクが出る
- サイドバーの「👤担当タスクのみ / 🌐全タスク」トグルを「担当タスクのみ」にする（ダッシュボード・リスト・カンバン・ガントが自分のタスクだけになる）
- **リスト**のフィルターで「👤自分担当のみ」「📅今週期限のみ」を選ぶ。「まとめ方」を担当者別にする方法もある
- 検索（Ctrl+K）にタスク名の一部を入れる

見つからないときは、**表示部署**を確認します。サイドバーの「🏢 部署名」（複数の部署に所属している人だけに出ます）で選んでいる部署の、PJ・タスク・メンバーだけが表示されます。

## WBSを取り込む（PC）

外部で作ったWBS（ガント）を、プロジェクトとして取り込めます。サイドバー「プロジェクト」見出しの「＋」の隣の「📥」、またはPJ行の「⋮」→「WBSを取り込む」から開きます（ゲストモードには出ません）。

1. `.xlsx`、または同じ列の表を持つ Markdown（`.md`）を選びます。
2. 取り込み先を選びます。「新しいPJを作る」（PJ名は1行目のタイトルかファイル名が初期値）か、「既存のPJに追加する」（同名のグループがあればそこへ入れます）。
3. 一覧で、階層・名前・日付・先行タスク・完了・警告を確認し、「登録する」を押すと初めて書き込まれます。途中で失敗したときは、書き込んだ分を取り消します。

| 列（見出しの名前で探します） | 内容 |
|---|---|
| ID | 1／1.1／1.1.1 など |
| 階層 | G＝グループ、P＝親タスク、C＝その子タスク |
| タスク名 | |
| 開始日・終了日 | Excelの日付、`2026-01-05`、`2026/01/05`、`2026/1/5` |
| 先行タスク | IDをカンマ区切り（例：`2.3.3, 2.4.1`）。見つからないIDは警告して読み飛ばします |
| 備考 | 「完了」「マイルストーン」「ユーザー」「仮」を「・」でつなぎます。完了＝ステータス完了、マイルストーン＝タスクに◆も追加、ユーザー・仮＝タグ、それ以外の語＝メモ |
| 担当者（任意） | メンバーの短縮名か名前。無い・照合できないときは取り込む本人 |

`.xlsx` は「ID」と「タスク名」を含む行を見出しとして探し、その下のIDが空の行（凡例など）の手前までを読みます。シートが複数あるときは「ガントチャート」を優先します。「日数」列や、右側の日付ごとのバー表示は読みません。
