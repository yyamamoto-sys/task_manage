# FAQ・よくある詰まり

## 全般

### ログインできない / 「アクセス権がありません」と出る
ログインはメールアドレスとパスワードで行います。ログインしたメールアドレスがメンバーとして登録されていないと「アクセス権がありません」と表示されます。
所属部署の管理者に、同じメールアドレスでのメンバー登録を依頼してください。
メンバーの登録は各部署の管理者が行います。管理者が誰かは、すでに使えている同じ部署の人なら、設定の「🛟 困ったとき」にある「この部署の管理者」で確認できます。管理者は **設定 → 部署の管理 → メンバー**から登録します（メールアドレスは必須）。

### パスワードを忘れた
ログイン画面の「パスワードをお忘れの方はこちら」を押し、登録したメールアドレスを入れて「再設定のメールを送る」を押します。届いたメールのリンクを開くと「新しいパスワードを設定」の画面が出ます。6文字以上のパスワードを2回入れて設定すると、そのままアプリを使えます。

- メールが届かないときは、迷惑メールフォルダを確認してください。それでも届かないときは、所属部署の管理者に連絡してください。
- メールのリンクは一度しか使えず、短い時間で無効になります。「このリンクは無効か期限切れです」と出たら、もう一度メールを送ってください。
- 再設定の画面を開いたまま閉じてしまっても、パスワードを決めるまではアプリには入れません。もう一度メールのリンクを開くか、ログイン画面から送り直してください。
- 続けて送るときは、60秒あけてください（送信ボタンが止まります）。送りすぎると届かないことがあるため、届かないときは少し待ってから送り直してください。
- 画面には、登録されているかどうかにかかわらず同じ文言が出ます（他人があなたのアカウントの有無を調べられないようにするためです）。
- ログインできている状態でパスワードを変えたいときは、設定 → 🔑 アカウント →「パスワードを変更」から変えられます。

### ガイド（📖）が見つからない
ガイドはサイドバー最下部の「⋯」を開くと出ます（既定では折りたたまれています）。

![サイドバー最下部の「⋯」を開いたところ。ガイド・設定・招待コードを入力・テーマ切替・ログアウトが並ぶ模式図](../_img/sidebar-more-menu.svg)

`?` ボタンがあるのはダッシュボード・AIツール・設定ページの3つの画面だけです。カンバン・ガント・リスト・ワークロード・OKRモードには `?` ボタンがありません。

### 使いにくい点・不具合を伝えたい
ベル（🔔）上部の「💬 ご意見を送る」（または設定 → 困ったとき → ご意見を送る）から、一言で送れます。そのときの画面の状況（画像や文字は含まない）も一緒に送れます。詳しくは[ご意見・不具合を送る](./feedback.md)を参照してください。

### 画面が真っ白／古いままで動かない
一度 **ブラウザのリロード（Ctrl+R / Cmd+R）** を試してください。
新しい版の公開直後に、開いたままの画面で未読込の画面を開くと読み込めないことが稀にあります。入力中などでなければ自動で更新され、そうでなければその画面の位置に再読み込みの案内が出ます（ほかの画面は使えます）。
再読み込みが必要な重要な更新があったときは、画面上部のバーでお知らせします（出ていても操作はできます）。
しばらく（10分以上）操作しないと、新しい版があれば画面が自動で切り替わります。入力中・未保存の編集があるとき、AI相談の会話中、ダイアログを開いているときは切り替わりません。「勝手に再読み込みされた」ときはこの仕組みです。

### モバイルでも使える？
基本は PC 向けです。モバイルでも開けますが、OKRモードの記入など入力の多い作業は PC で行ってください。
モバイルのヘッダーには📖 ガイドのボタンがありません。ガイドは「設定 → 困ったとき → ガイドを開く」から開きます。

### 通知が届かない
設定画面（「⋯」→「⚙ 設定」）の「🔔 通知の受け取り方」に、通知のオン・オフと「通知が届かないとき」の確認手順があります。
Windows通知は PC・ブラウザごとの設定です。ブラウザを完全に終了していると届きません。

## 計画モード

### 自分のタスクが見当たらない
- **表示部署が違う**可能性があります。複数の部署に所属している場合、サイドバーの「🏢 部署名」で選んでいる部署のPJ・タスクだけが表示されます。別の部署のPJは、その部署を選ぶと表示されます
- サイドバーの **「👤自分 / 🌐全件」トグル**が「自分」になっている可能性があります。「自分」では、自分が担当のタスクを持つPJだけが一覧に出て、ダッシュボード・リスト・カンバン・ガントも自分のタスクだけになります。既定は「自分」ですが、自分担当のPJが0件で全件があるときは「全件」で始まります
- 完了・アーカイブしたPJは、サイドバーの「🗄 完了・アーカイブも表示」をオンにすると一覧に出ます
- ダッシュボードの「今週のタスク」は、「全員 / 自分のみ」で自分担当分だけ抽出できます。「🔔 自分のリマインダー」にも自分の期限の近いタスクが出ます
- リストでは、フィルターの「👤自分担当のみ」や担当者フィルタが使えます

![表示部署と見える範囲の模式図](../_img/display-scope.svg)

### 変更したのに保存されていない / 保存ボタンが押せない
タスクの編集は自動保存ではなく、編集面の **「保存」ボタン**（または Enter／Ctrl+Enter）で確定します。
変更が無いときは、ボタンが「✓ 保存済み」の表示になって押せなくなります。変更するとまた押せるようになります。
未保存のまま閉じたり別のタスクへ移ったりすると、確認が出ます。
詳しくは [タスクの登録と更新](../02_modes/tasks.md) を参照してください。

### タスクを「完了」にできない
先行タスク（このタスクの前に完了すべきタスク）が未完了だと、完了にできません。先行タスクを完了または中止にしてから、もう一度試してください。

### タスクの担当者を変えると過去のタスクの動きが変わって見える
ガント・カンバン・リストの3つのビューは、すべて同じデータを見ています。
各タスク・PJの編集面の下部にある **「変更履歴」**で、直近20件（90日分）の「いつ・誰が・何を」変えたかを確認できます。各行の「↺ 元に戻す」で変更を戻せます（一般メンバーが戻せるのは自分の変更だけで、管理者は全員分を戻せます）。

### CSV出力したい
リストビュー → ツールバー右端の「⋯」→「⭳ CSV出力」から。

## OKRモード

### OKRモードで何をするのか
OKRモードは個人の四半期KRを管理する画面です。KRタブを選び、月の計画・実施記録・振り返りを記入します。週ごとの目標状態と自己評価（◯△✕）は、使いたい人だけが使う任意の補助機能です。正本は Kintone の個人OKRです（[全体像](../00_overview.md)）。
使い方は [個人OKRの使い方](../02_modes/personal-okr.md) を参照してください。

### タスクのタスクフォース欄に TF が出てこない
- タスク追加では、現在のクォーターに属する TF だけが出ます
- タスク編集の「＋ タスクフォースを追加」では、タスクの期日（無ければ開始日）が属するクォーターの TF だけが出ます
- 次Qへの TF の移動・新設が済んでいない可能性があります。管理者に確認してください（[四半期切替の手順](../04_workflows/quarter-rollover.md)）

### クォーターが変わった時の手順は
1. KR ごとに次QのTF構成を決める
2. 管理者が設定 → 部署の管理 → Task Force・ToDoで、次QへのTF移動・新設を行う
3. メンバーに変更を周知する

→ [四半期切替の手順](../04_workflows/quarter-rollover.md)

## AI機能

### AIの使用量は確認できる？
管理者が、設定（⚙）→ 部署の管理 → AI使用量で、intent ごとの消費トークン・回数を確認できます。一般メンバーには表示されません。

### AIに渡される範囲はどこまで？
AI相談では、表示部署のアーカイブ以外の全PJと、その全タスク（コメントを含む）が渡されます。他のメンバーが担当するタスクの名前・コメントも含まれるため、コメントには機密情報を書かないでください。
contribution_memo・会議ノート・個人OKRのメモは渡されません。
詳しくは [AI相談・資料インプット](../02_modes/consultation.md) の「AI に渡される範囲」を参照してください。

### AI相談に添付できる形式は？
Word（.docx）・Excel（.xlsx）・PowerPoint（.pptx）・PDF・HTML・テキスト（.txt／.md／.csv）です。複数まとめて添付できます。画像と旧形式（.doc／.xls／.ppt）は添付できません。旧形式は Office で新しい形式に保存し直してください。ファイルは1つ20MBまでです。Excel の非表示のシート・PowerPoint の非表示のスライドは送られません。1回の相談で送る文字は資料の合計で30,000字までで、超えた分は切り捨てられます。詳しくは [AI相談・資料インプット](../02_modes/consultation.md) の「資料を添付して相談する」を参照してください。

### AIの返答が遅い／止まる
- 大きいファイル（数十ページのPDF・1時間以上の文字起こし）を投げると 30〜60秒かかります
- 生成中は経過秒数が表示され、時間がかかっているときは「通常より時間がかかっています」と出ます
- 1分待っても応答しない場合、リロードして再実行してください
- それでも続くなら山本さんに連絡

## エラー表示

### （全社スーパー管理者向け）届いたエラーを Claude に調べさせたい
ベル 🔔 を開き、「⚙ 通知設定」の真下の「🛡 エラーをコピー」を開く。未読の「利用者の画面でエラー」に対応するエラーが並ぶので、チェックを入れて「📋 選んだエラーをコピー」を押し、Claude に貼る。誰の画面かは文面に入らない（発生した人数だけ）。通知を既読にすると一覧から消える。コピーしても既読にはならない。

### `PGRST205` — テーブルが見つからない
DBスキーマがまだ反映されていない状態です。山本さんに伝えてください。

### `42501` — permission denied
DBアクセス権限の不足。エラー本文に修正用 SQL が入っているはずなので、山本さんに転送してください。

### `dynamically imported module` のエラー
新しいデプロイ直後に古いチャンクを読みに行った状態。**リロード**で解消します。

## それでも解決しない時

山本さんに以下を添えて連絡：
1. 何をしようとして
2. どこで詰まったか（画面のスクショ）
3. エラーメッセージ（あれば）
4. 使っているブラウザとOS
