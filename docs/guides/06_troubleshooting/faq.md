# FAQ・よくある詰まり

## 全般

### ログインできない / 自分の名前が一覧に無い
管理者（山本さん）にメンバー登録をしてもらってください。
**設定 → メンバー管理**から登録するとすぐ反映されます。

### 画面が真っ白／古いままで動かない
一度 **ブラウザのリロード（Ctrl+R / Cmd+R）** を試してください。
新しいデプロイ直後に、古いチャンクが消えていてエラーになることが稀にあります（自動回復するようには作っていますが、リロードが最速）。

### モバイルでも使える？
基本は PC 向けです。モバイルでも開けますが、OKRモードの記入など入力の多い作業は PC で行ってください。

## 計画モード

### 自分のタスクが見当たらない
- サイドバーの **「自分のPJのみ」フィルタ**がオンになっている可能性があります（既定はオン）
- ダッシュボードでは「自分のタスク」セクションで自分担当分だけ抽出できます
- リストで担当者フィルタを使うのも有効

### タスクの担当者を変えると過去のタスクの動きが変わって見える
タスクの履歴は変更ログとして残ります。ガント・カンバン・リストの3つに表示されますが、すべて同じデータを見ています。

### CSV出力したい
リストビュー → 右上の CSV出力ボタンから。

## OKRモード

### OKRモードで何をするのか
OKRモードは個人の四半期KRを管理する画面です。KRタブを選び、今月の計画・週の目標状態・自己評価（◯△✕）を記入します。正本は Kintone の個人OKRです（[全体像](../00_overview.md)）。

### タスクのタスクフォース欄に TF が出てこない
- タスク追加では、現在のクォーターに属する TF だけが出ます
- タスク編集の「＋ タスクフォースを追加」では、タスクの期日（無ければ開始日）が属するクォーターの TF だけが出ます
- 次Qへの TF の移動・新設が済んでいない可能性があります。管理者に確認してください（[四半期切替の手順](../04_workflows/quarter-rollover.md)）

### クォーターが変わった時の手順は
1. KR ごとに次QのTF構成を決める
2. 管理者が設定 → タスクフォースで、次QへのTF移動・新設を行う
3. メンバーに変更を周知する

→ [四半期切替の手順](../04_workflows/quarter-rollover.md)

## AI機能

### AIの使用量は確認できる？
設定（⚙）→ AI使用量パネルで、intent ごとの消費トークン・回数を確認できます。

### AIに渡される範囲はどこまで？
OKR運用に必要な範囲（O・KR・TF・ToDo・タスク・contribution_memo）はすべて渡してOKという方針です（2026-05-13以降の方針改定）。
個人の私的メモなど明示的に「AIに渡さない」とした項目だけ除外されます。

### AIの返答が遅い／止まる
- 大きいファイル（数十ページのPDF・1時間以上の文字起こし）を投げると 30〜60秒かかります
- 1分待っても応答しない場合、リロードして再実行してください
- それでも続くなら山本さんに連絡

## エラー表示

### `PGRST205` — テーブルが見つからない
DBスキーマがまだ反映されていない状態です。山本さんに伝えてください。

### `42501` — permission denied
DBアクセス権限の不足。エラー本文に修正用 SQL が入っているはずなので、山本さんに転送してください。

### `dynamically imported module` のエラー
新しいデプロイ直後に古いチャンクを読みに行った状態。**リロード**で解消します。

## それでも解決しない時

山本さんに以下を添えて連絡：
1. 何をしようとして
2. どこで詰まったか（画面のスクショ）
3. エラーメッセージ（あれば）
4. 使っているブラウザとOS
