# ご意見・不具合を送る

使いにくい点・困ったこと・不具合を見つけたら、その場で管理者に送れます。そのときの画面の状況も一緒に送れるので、「どの画面で何をしていたか」を聞き返されずに済みます。サンプル閲覧（ゲスト）では使えません。

## 送り方（10秒）

1. 画面右上のベル（🔔）を開き、上部の「💬 ご意見を送る」を押します。設定の「🛟 困ったとき」→「ご意見を送る」からも開けます。
2. 一言書きます（1,000字まで）。種類（要望・不具合・その他）は選んでも選ばなくても構いません。もう一度押すと選択を外せます。
3. 「送信」を押します。Ctrl+Enter（Macは ⌘+Enter）でも送れます。

「社外秘・個人情報は書かないでください」。書いた内容は、メールアドレスやトークンらしき文字列が自動で伏せ字になりますが、それ以外は伏せません。

## 一緒に送る「画面の状況」

「画面の状況を付ける」は最初からオンです。次の項目だけを送ります。**画面の画像や、タスク名・プロジェクト名・コメント・検索した語などの文字は送りません。**

| 項目 | 内容 |
|---|---|
| 画面 | 開いていた画面（リスト・ガント・カンバン・設定 など）と、計画／OKRのモード |
| アプリの版・ブラウザ | 版、ブラウザの名前と大きな版数、OS（User-Agent の全文は送りません） |
| ウィンドウ | 幅×高さ、拡大率（ブラウザの拡大とOSの表示倍率の合算）、PC／モバイルの別 |
| 表示部署・選択 | 表示部署のID、選んでいたプロジェクトとタスクのID、選択していたタスクの件数（名前は送りません） |
| 表示設定 | まとめ方・並び順・絞り込みの有無と種類（検索欄は「入力があるか」だけ） |
| 直前の操作 | 直近5回のクリックの種類（ボタン・行など）と位置。押した場所の文字は送りません。キー入力は記録しません |

- 「送る内容を見る」を開くと、人が読む形の要約と、実際に送る JSON をそのまま確認できます。
- 状況は、モーダルを開いた瞬間のものが送られます（開いたあとの操作は含まれません）。
- 直前のクリックは、このブラウザのメモリにだけ保持し、送るときにだけ送ります。ベルやこのモーダルの中のクリックは含めません。
- 「画面の状況を付ける」のチェックを外すと、種類・コメント・画面名・アプリの版だけを送ります。

## 送ったあと

- 送った内容は、同じモーダルの「送った内容と状況」タブで確認できます。状態は管理者が更新します。

| 状態 | 意味 |
|---|---|
| 新規 | まだ対応していない |
| 対応中 | 対応を始めた |
| 対応済み | 対応した |
| 見送り | 今回は対応しないと決めた |

- 送信者の名前は、全社スーパー管理者にだけ表示されます。ほかのメンバーや部署の管理者には見えません。
- 同じ内容を続けて送ると、1件にまとめます。送れるのは **1時間に3件・1日に10件**までです。上限に達したときは、その理由が画面に出ます。
- 画面の状況は受信から90日で消えます。対応済み・見送りのご意見は、状態を変えてから180日で削除されます。

## うまく送れないとき

- 「ご意見の機能の準備がまだ終わっていません」と出たときは、管理者に連絡してください（データベースの更新待ちです）。
- 画面が固まっているときは、先に[再読み込み](./faq.md)を試してください。
