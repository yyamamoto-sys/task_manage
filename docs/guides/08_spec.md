# 機能仕様書（一般メンバー向け）

## 1. この文書について

- 対象：管理者ではない一般メンバー。v3.139 時点の仕様をコードから確認してまとめています
- 目的：何がどこでできるか、誰に何が見えるか、AIに何が送られるかを1か所で確認できるようにする
- 管理者専用の機能は載せていません（設定の「🔧 部署の管理」、OKR構造の登録、お知らせの送信など。すべて「管理者のみ」）
- 画面操作の手順は各画面のマニュアルを参照してください。用語は[用語集](./_meta/glossary.md)にあります
- 配置はPC（幅768px以上）を基準に書いています。モバイルの違いは「5. 既知の制限」にまとめました

## 2. 画面ごとの機能一覧

### 2-1. 画面の骨格

![画面の全体図。サイドバー・メイン領域・ベル・＋ボタン・AIパネルに番号を振っている](./_img/screen-overview.svg)

サイドバー最下部の「⋯」の中に、ガイド・設定・招待コード・テーマ切替・ログアウトがあります。

![サイドバー最下部の「⋯」を開くと、ガイド・設定・招待コードを入力・ライト／ダーク切替・ログアウトの5項目が出る図](./_img/sidebar-more-menu.svg)

| 機能 | どこから | できること |
|---|---|---|
| モード切替 | サイドバー最上段「📋 計画」「🎯 OKR」 | 計画モード（タスク管理）と OKRモード（個人OKR）を切り替える。初めて OKR を押すと紹介が出る |
| 検索 | サイドバー「🔍 検索」／Ctrl+K | タスク名・PJ名の部分一致検索。ビューを開く・新規タスク追加・AIに相談もここから |
| ベル（🔔） | 画面右上 | お知らせの一覧、未読数のバッジ、すべて既読、通知設定への入口 |
| ＋（FAB） | 画面右下（計画モードのみ） | 「＋ タスクを追加」「◆ マイルストーン追加」「💬 AIに相談する」 |
| ショートカット一覧 | 右下「⌨」 | Ctrl+K（検索）・Ctrl+Z（元に戻す）と、現在のビューの操作を表示 |
| サイドバーの幅変更 | サイドバー右端をドラッグ | 140〜420px で変更。ダブルクリックで既定幅（160px）に戻る |
| ガイド | 「⋯」→「📖 ガイド」／各画面の `?` | 全画面のマニュアル。ツアーの再生もここから |

`?` ボタンが付いているのは、ダッシュボード・AIツール・設定ページだけです。

### 2-2. タスクの登録と編集

![タスクを保存するまでの流れ。入口、編集、「保存」を押す、の3段階で、自動保存ではないことを示す図](./_img/task-save-flow.svg)

| 機能 | どこから | できること |
|---|---|---|
| タスク追加 | 右下「＋」／Ctrl+K／カンバン各列の下／カレンダーの日付セル | タスク名・担当者・開始日・期日・優先度・KR・TF・PJ・親タスク・子タスク・メモを入力して登録 |
| 子タスク追加 | リストの最上位タスク行の「＋ 子タスク」 | 親を固定して追加。階層は「親→子」の2層まで |
| タスク詳細・編集 | リスト・カンバン・ガントの行／カード／バーをクリック | ステータス・担当者・日付・工数・コメント・先行タスクなどを編集。PCは右パネル、モバイルは下からのシート。**タグの編集欄はモーダル版の編集画面（モバイルのシート、ダッシュボード等から開くモーダル）にだけあり、PCの右パネルにはない** |
| 保存 | 編集面の「保存」／Enter／Ctrl+Enter | 自動保存ではない。変更がなければ「✓ 保存済み」。未保存のまま閉じる・移動すると破棄の確認が出る |
| 即時反映の項目 | 編集面 | 先行タスク・追加PJ・タスクフォース・子タスクの付け外しは、押した時点で保存される |
| ステータス | 編集面／カンバンのドラッグ／一括バー | ToDo・進行中・完了・保留・中止の5種。先行タスクが未完了だと「完了」にできない |
| 担当者 | 編集面／一覧のセル／一括バー | 複数人を設定可。候補は、表示部署のメンバー、そのPJの参加者（他の部署の人・招待で参加した人を含みうる）、今の担当者 |
| コメント・メンション | 編集面「コメント・メモ」 | `@名前` でメンション。**相手に通知が飛ぶのは、編集画面（モーダル版・PCの右パネルとも）で書いて「保存」したとき、または「タスクを追加」の登録画面で書いて「追加」したとき**。どの画面でも @ の候補が出る。ダッシュボードの「自分へのメンション」は、コメントに `@名前` が入っている未完了のタスクを文字列で拾うため、どの画面で書いても出る |
| 削除・元に戻す | 編集面「🗑 削除」／Ctrl+Z／トーストの「元に戻す」 | 削除は確認のうえ論理削除。**モーダル版の編集画面でもPCの右パネルでも**、削除すると「元に戻す」付きのトーストが出て、直後なら Ctrl+Z でも戻せる |
| 複製 | リスト・カンバンで複数選択→「📋 複製」 | 日付の基準移動・名前の一括置換をプレビューして複製 |
| 変更履歴 | 編集面・PJ設定の下部 | 直近20件。「↺ 元に戻す」は自分の変更のみ（管理者は全員分） |

### 2-3. 5つのビュー

| 機能 | どこから | できること |
|---|---|---|
| ダッシュボード | サイドバー「メニュー」 | 期限超過・今日締切などのタイル、自分のリマインダー、期限アラート、PJ進捗、自分へのメンション。「全PJをAI分析」 |
| PJカルテ | PJを選ぶ | 目的・期間・担当者別負荷・マイルストーン。「✨ このPJをAI分析」 |
| カンバン | サイドバーの「メニュー」から | ドラッグで状態変更。進行中は「WIP n / 上限 4」（超過は警告のみ）。複数選択で一括操作 |
| ガント | サイドバーの「メニュー」から | PJ別／人別。バーのドラッグで日程変更。依存の矢印・クリティカルパス・ベースラインの表示 |
| リスト | サイドバーの「メニュー」から | ツールバーでまとめ方・フィルター・並べ替え・検索。セルのクリックで直接編集。CSV出力 |
| 番号順に並べ直す | リストのツールバーの並べ替えボタン（現在の並べ方を表示する。例「↕ 期日順」）の中の「🔢 タスク名の番号順に並べ直す」 | タスク名の先頭の番号で並べ直す。全員の画面に反映されるため確認が出る |
| ワークロード | サイドバーの「メニュー」から | メンバー別の担当件数と負荷（表示部署のメンバーのみ） |

### 2-4. プロジェクトと招待

| 機能 | どこから | できること |
|---|---|---|
| PJ作成 | サイドバー「プロジェクト」の「＋」 | 新規作成、または他のPJからタスク・日付を引き継いで作成 |
| PJ行の「⋮」 | サイドバーのPJ行 | 「このPJの設定」「完了にする」「アーカイブ」「activeに戻す」。部署の全メンバーが使える |
| PJ設定 | 「⋮」／PJカルテ | 基本情報の編集、招待コードの発行（有効24時間）、関わるメンバーの確認 |
| 招待コードを入力 | 「⋯」→「🎫 招待コードを入力」 | 受け取った招待コードでそのPJに参加する |
| 「自分／全件」 | サイドバー「プロジェクト」 | 自分が担当のタスクを持つPJだけに絞る。4つのビューのタスクも自分分に絞られる |

### 2-5. AI機能

| 機能 | どこから | できること |
|---|---|---|
| AIパネル | サイドバー「✨ AIツールを開く」 | 右側に開く。「💬 相談」「📄 資料インプット」の2つのタブ |
| 相談 | AIパネル | 影響確認・シミュレーション・現状診断・締切の逆算・スコープ変更の相談。提案カードの「反映する」を押して初めて反映。タスク名・状態の一括変更も可 |
| 資料インプット | AIパネル | 議事録・資料（.vtt／.srt／.txt／.docx／.pdf／.html）から、タスク候補・決定事項・リスクを抽出して登録 |
| PJのAI分析 | PJカルテ／ダッシュボード | 健全性・進捗・リスク・次の一手を返す。PJ単体の結果は最新2件が部署内で共有される |

### 2-6. OKRモード（個人OKR）

OKRモードは個人OKRの1画面だけです。データは本人だけに見えます。

![個人OKRの1か月の流れ。今月の計画、週の目標（任意）、実施記録、振り返りの順に進む図](./_img/personal-okr-month.svg)

| 機能 | どこから | できること |
|---|---|---|
| 対象期・月の選択 | 画面上部 | 年・四半期・月を選ぶ。ウェイト合計が100%でないときは警告のみ |
| KRタブ・全体タブ | 対象期の下 | KRごとのタブと、月・四半期全体の振り返りを記録する「全体」タブ |
| KRの追加・取込 | 「＋ KRを追加」「📥 Kintoneから取込」 | 手入力、またはKintoneのPDF・テキストから取り込む。主経路は、決まった書式の規則による読み取り（AIを使わない）。書式から読み取れなかった部分だけ、予備としてAIで読む |
| 月の計画 | KRパネル | 取り組む内容・達成目標・リスク・ウェイトなど。前月をふまえたAI下書きあり |
| 週の目標・自己評価 | KRパネル | 任意。◯／△／✕で自己評価。未記入でもよい |
| 実施記録・振り返り | KRパネル | 実際に起きたことの記録と、自己評価%・GM評価%・GMコメントを含む振り返り。AI下書きあり |
| 「これから」 | KRパネル（当月） | 残り週数などは自動計算。AIの見立ては「✦ 見立てを出す」を押したときだけ動く |
| Kintone用コピー | 計画・振り返りの各欄 | 「📋 全文をコピー（Kintone用）」で一括コピー |

### 2-7. 通知と設定

| 機能 | どこから | できること |
|---|---|---|
| 期限リマインド | 自動（設定→通知で調整） | 平日（祝日を除く）に1日1回、自分担当の期限超過・今日期限をベルで知らせる。Windows通知は既定でオフで、本人が設定でオンにしたときだけ届く |
| 通知設定 | ベル／「⋯」→「⚙ 設定」→「🔔 通知」 | アプリ内・Windows通知の入切、種類ごとの設定、送信時刻（7:00〜19:00・30分刻み） |
| 管理者からのお知らせ | ベル | 受信と「確認しました」。送信は管理者のみ |
| プロフィール | 設定→プロフィール | 表示名・短縮名・アバター色の変更。メールと権限は表示のみ |
| 表示 | 設定→表示 | テーマ・言語・一覧の表示密度・サイドバー幅の初期化 |
| 困ったとき | 設定→困ったとき | 再読み込み・表示設定の初期化・ガイド・ツアーのやり直し・管理者の確認 |
| ラボ | サイドバー最下部「🧪」 | 体制図・関係グラフ・カレンダー・マイページ |

## 3. 誰に何が見えるか

![表示部署と見える範囲の図。自部署・兼務先・招待されたPJが、サイドバーの表示部署で切り替わる](./_img/display-scope.svg)

見える範囲は「データベースが決める範囲」と「サイドバーの表示部署による絞り込み」の2段で決まります。

| 立場・対象 | 見えるもの | 編集できるもの |
|---|---|---|
| 自部署の一般メンバー | 自部署のPJ・タスク・依存・メンバー・マイルストーン | 部署内のタスク（担当者以外のタスクも）、PJの基本情報・完了・アーカイブ、自分のプロフィール |
| 兼務（複数部署に所属） | 表示部署のデータ。サイドバーの「🏢 部署名」で切り替える | 表示部署の範囲。管理者権限は所属元（ホーム）部署のみ有効で、兼務先では一般メンバー扱い |
| 招待コードで参加したメンバー（招待用部署のみに所属） | 招待されたPJとそのタスク、PJの参加者 | 招待PJ内のタスク、PJの基本情報（PJ設定の画面に編集の制限はなく、データベースの制限も部署の範囲で判定するため、招待されたPJは編集できる） |
| 自分だけのもの | 個人OKR、自分への通知、通知・表示の設定 | 本人のみ（管理者・同僚には見えない） |

- 表示部署の切り替えは、アクセスできる部署が2件以上の人だけに出ます。1部署だけの人には出ません
- 切り替えると、PJ・タスク・メンバー・担当者の候補がその部署のものに入れ替わります。2部署を一度に並べて見る画面はありません
- 選んだ表示部署は、リロードしても維持されます（ブラウザごとに保存）
- 担当者の候補は、表示部署のメンバー、そのPJの参加者（他の部署の人・招待で参加した人を含みうる）、今の担当者です。すでに担当している他部署の人は、名前が「未担当」にならず表示されます
- できないこと：他人のプロフィール・権限・メールの変更、メンバーの追加と削除、部署の管理、他人の個人OKRの閲覧、他部署のデータの閲覧

## 4. AIに送られる情報の範囲

![AI相談で送られるものと送られないものの対比図](./_img/ai-data-scope.svg)

AIの呼び出しはブラウザからサーバー（Edge Function）を通り、Anthropic API に届きます。APIキーは画面側には出ません。利用の記録（メンバーID・機能名・トークン数）には、質問文と回答文は含まれません。**AI相談の質問文・回答文は、サーバーに保存しません**（この端末のブラウザに、会話の履歴が最大10件残ります）。ただし、次の結果はデータベースに保存されます。PJのAI分析は最新2件が保存され、部署内で共有されます。個人OKRの「これから」の見立て（personal_kr_outlooks）と、月の振り返りの下書き（personal_kr_review_drafts）は、本人だけが見える形で保存されます。

| 機能 | 送られるもの | 送られない・加工されるもの |
|---|---|---|
| AI相談 | 表示部署のアーカイブ以外の全PJと全タスク（PJ名・目的・状態・期間、タスク名・担当・状態・優先度・日付・工数・コメント）、メンバーの略称、OKRの情報（Objective名・KR名・今四半期のTF名とTFリーダーの略称）、相談文 | PJの貢献メモは含めない。コメント内のパス・メールアドレスは置き換える。IDは短縮IDに置き換える。他部署の氏名は送らない |
| 資料インプット | 貼り付け・添付の本文（先頭30,000文字）、PJ名、タスクの名前・担当・状態・期日、メンバーの略称 | タスクのコメント・工数は送らない。画像は添付できない |
| PJ単体のAI分析 | PJの基本情報、全タスク（コメントを含む）、マイルストーン、関係者の略称 | KR・TF・Objectiveと貢献メモは渡さない。コメント内のパス・メールアドレスは置き換える（先頭80文字まで） |
| 全PJのAI分析 | PJの概要、タスクの件数・期限超過・滞留、担当者別の進行中件数 | タスク個別の名前・コメントは送らない |
| 個人OKRのAI機能 | KRの内容、今月の計画、週の記録、タスクの件数サマリー、実施記録、直近メモ。**「前月をふまえて下書き」と全体タブの下書きは、これに加えて過去月の振り返り本文・自己評価%・GM評価%・GMコメントも送る（評価の情報がAIに渡る）** | タスクの生データは送らない。振り返りの下書きは、自己評価%・バンドの数値を出力しない（人が決める）。**一方、「これから」の見立てはバンド判定（現時点の見通し）を出力し、計画の下書きも狙いのバンドを提案する。どちらも確定は人が行う** |
| Kintone取込 | 規則で読み取れた場合は、AIには何も送らない。読み取れなかった部分があるときだけ、予備経路としてPDF・テキスト（GM評価・面談コメントを含みうる。評価の要約など抽出対象外の部分は送る前に削る）をAIに送る | どちらの経路で読んだかは確認画面に表示される（「⚙ 画面の構造から読み取りました（AI未使用）」「🤖 AIで読み取りました」）。入力画面の「🔒 AIに送信される内容」は、予備経路で送る最大の範囲を示す |

- AI相談は、部署内の他メンバーのタスク名・コメントを含めて毎回送られます。コメントに機密情報を書かないでください
- 個人OKRの「自分のメモ」は、個人OKRのAI機能にだけ使われ、AI相談には含まれません
- AIの返答は提案として出るだけで、「反映する」を押すまでデータは変わりません。反映後は元に戻せます

## 5. 既知の制限

| 区分 | 内容 |
|---|---|
| AIの利用回数 | 一般メンバーに日次・月次の上限はない。1ユーザー1分あたり20回まで。ゲスト（サンプル閲覧）は1ブラウザ1日3回、全体で1日10回 |
| AIの入出力量 | 資料インプットの入力は30,000文字まで。出力が上限に達すると途中で切れたことを示すエラーが出る |
| AI相談の会話 | 10ターンを超えると警告が出る。履歴はこの端末のみに最大10件保存 |
| AIの一括変更 | 対象が50件を超えると注意が出る（確認画面で1件ずつ除外できる） |
| 添付・処理時間 | PDF・Word・HTML は端末でテキスト抽出してから送る。数十ページのPDFは30〜60秒かかることがある |
| モバイル | PC向けが基本（768px未満は専用の配置）。ヘッダーに「ガイド」ボタンと表示部署の切替がなく、ガイドは「設定」→「困ったとき」から開く |
| ブラウザ | 対応ブラウザの明示はない。利用環境はPCブラウザとMicrosoft Teams埋め込み。Windows通知の手順はEdge・Chromeを例示している |
| Windows通知 | PC・ブラウザごとの設定。ブラウザを完全に終了していると届かない。Teams内では設定できない |
| 通知の種類 | メンション通知はWindows通知をオンにした人のみで、タブを開いている間に限る |
| 英語表示 | 一部の画面のみ（サイドバー・FAB・検索・ベル・設定など）。ダッシュボード・リスト・カンバン・ガントなどの本体は日本語のまま |
| 設定の保存先 | テーマ・言語・表示密度・サイドバーの状態・表示部署はブラウザに保存される。別のPC・ブラウザには引き継がれない |
| 同時編集 | 他の人が先に更新していると、保存時に上書きの確認が出る |
| 個人OKR | 未来の月は編集できない。評価の確定はKintone側 |
| 招待 | 招待コードは発行から24時間有効。招待先メールのドメインは許可リストで制限。配れるアクセスはそのPJ1件のみ |
| 変更履歴 | 90日間保存。表示は直近20件 |
| カンバン | 進行中のWIP上限は固定4件（超過は警告のみ） |
