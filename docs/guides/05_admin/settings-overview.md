# 設定パネル概要

サイドバー下部の **⚙ 設定**ボタンから、全画面で開きます。開くとカードの一覧が出て、カードを押すとそのページが開きます（戻るには上部の「← 設定」）。
一覧は3つの見出しに分かれます。

| 見出し | 誰に出るか |
|---|---|
| **個人** | 全員（プロフィール・アカウント・表示・通知の受け取り方・困ったとき。[設定画面](../02_modes/settings.md)を参照） |
| **部署の管理** | 部署の管理者・全社スーパー管理者（部署に管理者が1人もいない間は全員。ただし「お知らせの送信」は管理者のみ） |
| **アプリの管理** | 全社スーパー管理者 |

「部署の管理」の見出しの行に、編集できる人の説明と、表示部署が複数あるときは「編集対象の部署」が出ます。編集対象は、サイドバーの「表示部署」に従います。切り替えるにはサイドバーを使います。

## 部署の管理のページ

| ページ | 内容 |
|---|---|
| **Objective・KR** | 今期の目標（期間・タイトル・purpose）と、Objective にぶら下がる結果指標（KR）。KintoneのPDFからの取込も |
| **Task Force・ToDo** | KR にぶら下がる実働ユニット（TF）と、その下のToDo。上部のクォータータブ（1Q〜4Q）でTF自身が属するQを移動・確認 |
| **プロジェクト** | PJ の登録・編集・削除。オーナー・状態（active/archived）・期間 |
| **メンバー** | 追加・編集・論理削除。表示名・短縮名・メール・権限・部署 |
| **メンバータグ** | 部署・チームの目印として（権限制御には未使用） |
| **部署** | 部署の追加・名前の変更・削除（全社スーパー管理者は追加と削除ができる）。PJ の中の区分（グループ）はこのページではなくリストで編集する |
| **プロジェクト招待** | 他部署への招待の一覧と取り消し |
| **AI使用量** | メンバー別・月別の消費トークン・回数 |
| **お知らせの送信** | 部署メンバーへの連絡（確認ボタン・期限つき）と送信履歴 |

## アプリの管理のページ（全社スーパー管理者）

| ページ | 内容 |
|---|---|
| **ローディングのヒント** | 読み込み中に出すヒントの編集 |
| **バックアップ** | 日次バックアップの状況・ダウンロード・今すぐ実行 |
| **期限リマインドの実行状況** | 期限通知の送信記録・Windows通知の登録数・今すぐ実行（dryRun） |
| **利用者の画面のエラー** | 利用者の画面で起きたエラーの一覧・詳細・解決済みの切り替え |
| **ご意見・不具合** | 利用者が「💬 ご意見を送る」から送ったご意見の一覧（既定は新規＋対応中）・詳細（画面の状況）・状態の切り替え（押した時点で保存）・管理者メモ（利用者には見えない）・Claude 用にコピー。送信者名はこの画面だけに表示。画面の状況は90日で消え、対応済み・見送りは状態変更から180日で削除。詳しくは[ご意見・不具合を送る](../06_troubleshooting/feedback.md) |

## 推奨運用

### 期初
1. メンバー登録（短縮名2〜4字）
2. Objective・KR を確定
3. TF を登録（初Q分。クォータータブは自動的に現在のQ）
4. パイロットメンバーに通知

### 四半期切替
1. KR ごとに次QのTF構成（継続／変更／廃止／新設）を決める
2. 設定 → 部署の管理 → Task Force・ToDo の次Qタブで、継続TFを移動・新設TFを作成
3. メンバーに変更を周知

→ [四半期切替の手順](../04_workflows/quarter-rollover.md)

### 月初
- AI使用量を確認
- メンバー追加・削除（必要に応じて）

## 保存のしかた

入力フォームのあるページは「保存」ボタンで保存します（変更がないときは「✓ 保存済み」、変更したあとは「保存」、保存中は「保存中…」）。保存に失敗したときはフォームの下にエラーが残り、入力は消えません。保存していない変更があるまま別のページ・画面へ移ろうとすると確認が出ます。

## 注意点

- **論理削除のみ**：`is_deleted` フラグでの削除なので物理削除はしません。履歴は残ります
- **退職メンバーの扱い**：削除すると履歴に「（不明）」と表示されることがあるので、短縮名末尾に「（退）」を付ける運用がおすすめ
- **構造変更は影響範囲が広い**：KR/TF の削除は、紐づくタスク・プロジェクトのタスクフォース表示や、個人OKRの紐づけ先に影響します。慎重に

## エラー通知のコピー（全社スーパー管理者のみ）

ベルの「⚙ 通知設定」の真下に「🛡 エラーをコピー」欄がある。未読の「利用者の画面でエラー」に対応するエラーをチェックで選び、Claude にそのまま貼れる Markdown としてコピーできる（名前・メールは入らない）。詳細の確認・解決済みへの変更は従来どおり「アプリの管理」→「利用者の画面のエラー」。
