## 作業を始めるとき：リポジトリ外の資料について

このリポジトリは、clone した PC・運用者を問わず、リポジトリ内の文書だけで作業できるように書いてある。設計の正本は CLAUDE.md と `docs/dev/` 配下。

- 管理者（山本）の作業環境には、リポジトリ外の連絡用ファイル（`管理台帳_Claude間伝言板_*.md`。アプリの位置付けの検討と開発作業の間で依頼と回答をやり取りする場）がある。**その環境に存在する場合のみ**読み、無い環境では読まずに進めてよい。
- 伝言板がある環境では、その「使い方」に従う（自分宛ての依頼は「状態」「回答」欄だけを書く、等）。
- 機密値（鍵・API キー・プロジェクト識別子・URL）とセキュリティの弱点の突き方は、リポジトリにもリポジトリ外の連絡用ファイルにも書かない。
- 引継ぎ・連絡不能時の最低限の情報は `docs/dev/handover-checklist.md`、運用手順は `docs/dev/runbook.md` にある。
