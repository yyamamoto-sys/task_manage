# task_manage データビズ・ウィジェット追加 — 集計→テスト→インラインSVG→Card の型

## 目的
このアプリに何度も「タスクデータから集計してグラフ/数値で見せる」ウィジェットを足してきた（ガントの締切見通し・完了ペース、ダッシュボードの同2種、リストのグループ集計）。毎回同じ4ステップ・同じ注意点になるので手順化する。外部チャートライブラリは入れない方針（CSP/バンドル増を避ける・インラインSVGで足りる）。

## 手順（4点セット）
1. **純粋集計関数を `src/lib/` に作る**（例 `src/lib/computeDueForecast.ts`）
   - 入力はスコープ済みタスク配列（呼び出し側で `filteredTasks` 等＝PJ選択/自分のみを尊重して渡す。関数内で素の全件参照はしない）。
   - **`today` は引数で受け取る**（`Date.now()`/`new Date()` に依存させない＝テスト容易＆TZ事故回避）。
   - **日付の切り出しは `slice(0,10)` 方式**（`due_date`/`completed_at` 等）。`toDate()`（ローカルTZ変換）は日付跨ぎでズレるので集計では使わない（`payloadBuilder.ts` 等の既存流儀に合わせる）。
   - `is_deleted`除外・ステータス条件（未完了/done）・日付なしの扱いを明示。欠損でクラッシュしない。
2. **`__tests__` に単体テスト**（境界を突く）：バケット境界・当日/週末・日付なし除外・done/未完了除外・論理削除除外・全未入力時のnull返し 等。`today`を注入してDate非依存で検証。
3. **インラインSVGコンポーネント**（例 `DueForecastChart.tsx`／`VelocityChart.tsx`。外部ライブラリ不使用）
   - `viewBox="0 0 W H"` ＋ `width:100%` でレスポンシブ。色は全て `var(--color-*)` でダークモード自動対応。
   - **dataviz原則**：マグニチュードは**単一色相**（accent）、**状態色（danger赤等）は予約**して意味の分離にだけ使う、薄い基線/グリッド、**端点や「今日」「山場」を強調**、各マーク/点に `<title>` ツールチップ。
4. **Cardに配置**：既存の `Card`（＋2カラムグリッド等）に入れる。既存レイアウト・並び順は壊さない。

## これまでの採否の方針
- **実用重視、飾りは入れない**：3値ステータスの円グラフやゲージ化は chartjunk として不採用にしてきた。「行動に繋がるか」で採否を決める（締切の山場・消化ペースは採用）。
- **デプロイ**：main へ push すると Vercel が本番へ自動デプロイされる。検証は `npx tsc --noEmit`／`npx vitest run`／`npx eslint src`（新規エラーを増やさない・ベースライン比較）／`npm run build`。
- **見た目の確認**：ブラウザでの目視確認は、`npm run dev` で人が行ってきた。
- DB マイグレーションは基本不要（既存カラムの集計）。必要な場合は SQL 全文を提示し、本番・開発の両方に適用する（`docs/dev/lessons-learned.md` §1 のデプロイ順序に注意）。

## やらないこと・注意点
- 外部チャートライブラリ（recharts等）を入れない＝インラインSVG。
- `completed_at` を `toDate()` で日付化しない（TZ日付跨ぎでズレる／`slice(0,10)`）。
- 集計関数を `Date.now()` 依存にしない（テスト不能になる）。
- 素の `s.tasks`/全件を集計に使わない（部署/PJ/自分のみスコープを尊重）。

## 合格基準（これが満たせたら正しく動いている）
- 集計関数が `today` 注入でDate非依存にテストでき、境界テストが緑。
- チャートに外部ライブラリimportが無く、ライト/ダーク両方で視認でき、`<title>`ツールチップが出る。
- `tsc`/`vitest`/`eslint(新規0)`/`build` 全通過。DBマイグレ不要（既存データのみ）。

## 実例（実物）
- 集計：`src/lib/computeDueForecast.ts`（超過バケット＋今日〜13日先を日別集計・7テスト）／`computeWeeklyVelocity.ts`（completed_atを週=月〜日で集計・`slice(0,10)`でTZ安全・7テスト）／`src/lib/list/groupSummary.ts`（完了率＋工数合計・全未入力はnull）。
- 描画：`src/components/dashboard/DueForecastChart.tsx`（単一accentバー・超過だけ赤・土日淡色・今日強調・最多日に「山場」・`<title>`）／`VelocityChart.tsx`（面＋2px線の単一系列・薄い水平グリッド・最終点を大きめ丸＋「今週n件」）。
- 避けた失敗：`completed_at` を `toDate()` で扱うと日付跨ぎでズレる → `slice(0,10)` に統一して回避（実際に採用した判断）。
